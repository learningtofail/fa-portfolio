# 0008: Retire the UTM, GTM and CAC Astro tools

Status: accepted.

## Decision

- The UTM Governance Auditor, GTM Container Auditor and CAC / LTV / Payback Calculator Astro tools are removed (components, lib modules, tests, fixtures). The vendored marketing tools (decision 0007) cover them: same-name UTM and GTM auditors, and the CAC, Margin & Payback Modeler, which also reports LTV and LTV:CAC.
- The old URLs `/tools/utm-auditor/`, `/tools/gtm-auditor/` and `/tools/cac-calculator/` stay alive as redirect pages generated by Astro (`redirects` in `astro.config.mjs`) to the matching `/marketing/*.html` page. No host change is needed. They are meta-refresh pages, not HTTP 301s.
- Multi-Touch Attribution and the Disclosure Language Checker stay. Nothing in the marketing set replaces them. www groups them with the marketing tools in one Marketing folder.
- The planned Astro A/B experiment analyzer is dropped from CLAUDE.md: `experiment-analyzer.html` already ships in the marketing set.

## Trade-offs

- The marketing pages do not follow the Orchis tokens or the no-inline-styles rule (decision 0007). The retired tools did.
- Saved inputs in the old tools (none were stored) do not carry over.
- The `StatCard` tone type moved into `StatCard.jsx`, since it lived in the removed CAC module.

## What would change it

Wanting the old tools back as Astro pages, or a need for real HTTP redirects (add them in Caddy).
